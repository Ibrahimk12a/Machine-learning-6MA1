# King County House Sales Analysis - Lab 4

### Dataset Description
This dataset contains house sale prices for King County, which includes Seattle. It includes homes sold between May 2014 and May 2015. It's a great dataset for evaluating simple regression models.

### Lab Objective
In this lab, I performed **Data Quality Assessment & Preprocessing** to prepare the data for machine learning models. I fixed incorrect data types, handled missing prices using median imputation, and removed outliers using the IQR method. Finally, I normalized key features and applied PCA to reduce dimensionality.
